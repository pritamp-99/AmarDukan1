# Sambalpuri Weaves Front-end

## Run locally

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Open:
- `http://127.0.0.1:4173/index.html`
- `http://127.0.0.1:4173/collections.html`
- `http://127.0.0.1:4173/product-detail.html`
- `http://127.0.0.1:4173/cart.html`
- `http://127.0.0.1:4173/checkout.html`
